## Phase 1: 即時実装（既存ラクミーデータのみ）

**119件が即座に実装可能。新規データ追加不要。**

### 代表指標

## Phase 2: 基盤整備（近期・既存運用の自然な拡張）

### Phase 2-A: シフト管理連携（10件、工数大）
- 新規テーブル: `shifts` (store_id, user_id, planned/actual時刻, position, hourly_wage)
- 対応指標: 人時売上高、人時粗利、時間帯別人件費率、シフト充足率、アイドル時間人件費率、労働生産性ランキング等
- **推定2-3ヶ月**

### Phase 2-B: マスタ整備（4件、工数小〜中）
- 席数マスタ: `stores.seat_count` 追加 → テーブル回転率
- レシピマスタ: `menu_recipes` + `recipe_ingredients` → 商品別原価率偏差
- 発注締切: `supplier_deadlines` → 発注遅延検知

### Phase 2-C: 実績入力拡張（4件、工数小）
- レジ実金: `cash_reconciliations` → レジ誤差率
- 廃棄記録: `waste_logs` → 廃棄率
- 賄い記録: `staff_meal_logs` → 賄い比率
- 入力タイムスタンプ: 既存テーブルに `submitted_at` → 実績入力遅延検知

## 実装優先度の提案

1. **Phase 1 (119件)** → まず全てダッシュボード化
2. **Phase 2-B, 2-C (8件)** → 小工数で効果大
3. **Phase 2-A (10件)** → シフト管理は労務管理とセットで推進価値大
4. **Phase 4-B (2件)** → 小工数で経営指標を厚くできる
5. **Phase 3 (7件)** → 顧客・マーケ・品質の横展開
6. **Phase 4-A (3件)** → 会計連携は投資家向け報告ニーズに応じて
