### 4.2 軸切替（X⇄Y 転置）

|------|-----|-----|------|

### 4.3 グルーピング機能

複数指標を意味単位でグルーピング。グループヘッダーで折りたたみ/展開可能。

```
┌─────────────────────────────────────────────────┐
│ 店舗   │    [売上系]       [収益性]     [効率性]  │
│        │ 売上 目標 達成率 │利益 粗利率 │FL率 人件費率│
│────────┼──────────────┼───────────┼──────────│
│ 店A    │ ¥1M  ¥1.2M 83% │¥200K 20%  │58%  25%   │
│ 店B    │ ¥2M  ¥1.8M 111%│¥400K 22%  │55%  24%   │
│ 合計   │ ¥3M  ¥3M  100% │¥600K 21% │56%  24.5% │
└─────────────────────────────────────────────────┘
```

### 4.4 ソート機能

- 列ヘッダークリックで昇順/降順
- 複数列ソート（Shift+クリックで第2ソートキー追加）
- グループ内の列順は ドラッグ&ドロップ
- グループ自体の順序も ドラッグ&ドロップ

## 5. 併記不可指標のハンドリング（UIフィードバック）

### 5.1 選択時の警告モーダル

ユーザーが併記不可の指標組合せを選んだ場合:

```
┌──────────────────────────────────────────┐
│ ⚠ 指標の併記に注意が必要です               │
├──────────────────────────────────────────┤
│ 選択された指標:                          │
│  A: 日次売上（リアルタイム系）           │
│  B: 年間予算達成率（年次）                │
│                                          │
│ 理由:                                    │
│  粒度差が大きく、同じ行で意味のある比較が│
│  困難です（秒単位 vs 年単位）              │
│                                          │
│ 提案:                                    │
│  ① 日次売上 → 月次売上に集約しますか？    │
│  ② 別レポートに分けますか？              │
│  ③ このまま表示しますか？（意味不明瞭）   │
│                                          │
│         [①集約][②分割][③強制表示][キャンセル]│
└──────────────────────────────────────────┘
```

### 5.2 軽微な警告（バナー表示）

```
┌──────────────────────────────────────────────┐
│ 💡 合計行のAVG系指標は加重平均で計算されます    │
│   ・客単価の合計 = Σ売上 ÷ Σ客数                │
│   ・FL率の合計 = Σ(FD+人件費) ÷ Σ売上          │
└──────────────────────────────────────────────┘
```

## 7. 追加機能提案（発展機能）

### 7.1 ダッシュボードテンプレート
**朝ミーティング用**「昨日実績」「今日の目標」「週次ペース」の定型フォーマット  
**月末締め用**「予実対比」「予算消化」「来月予測」の定型  
**経営会議用**「全社KPI」「業態別」「トレンド」の定型

### 7.2 AI予測指標
- 過去データから来月売上予測
- 異常検知（統計的外れ値）
- 推奨アクション提示

### 7.3 アラート・通知連携
- 閾値超過時にSlack/メール通知
- 未達ペース検知でプッシュ通知
- 月末3日前に予算消化警告

### 7.4 データストーリーテリング
- 選択した指標から自動で「気づき」を自然言語で生成
- 例: 「今月は売上+5%ですが、客数-2%のため客単価上昇が貢献」

### 7.5 ベンチマーク比較
- 社内ベンチマーク: 同業態ラベル内のトップ3店舗平均
- 業界ベンチマーク: 外部データ連携（将来）

### 7.6 条件付き書式の拡張
- 前年同月比でのカラー変化
- 達成率ゾーン別の背景色（90%以上=緑、70-90%=黄、70未満=赤）
- スパークライン（セル内ミニグラフ）

### 7.7 共同編集機能
- 本部管理者が作成したレポートを店長に送信
- コメント機能で店長→本部の報告
- チャット連携

### 7.8 レポートスケジュール配信
- 毎日朝8時にメール配信
- 毎週月曜日にPDF配信
- 毎月1日に前月サマリー配信

### 7.9 ドリルダウンの深化
- セルクリック → 時系列グラフ
- 時系列クリック → 日次内訳
- 日次内訳 → POSレシート単位
- 段階的に詳細化

### 7.10 カスタム指標ビルダー
- ユーザーが独自の計算式を定義
- 例: `(売上 - 客数×500) / 席数` = 席当たり実質粗利
- 権限: 本部管理者のみ作成可、店長は利用可
