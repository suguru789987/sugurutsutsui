## 経営重要度の定義

### 会社画面（本部・オーナー視点）

| ランク | 定義 | 判断基準 |
|--------|------|----------|
| S | 最重要（経営判断直結） | 収益性・投資回収に直結、取締役会/オーナー報告必須 |
| A | 重要（業績管理必須） | 月次業績報告の主要KPI、全店舗比較の基準 |
| B | 標準（管理対象） | 予実管理・進捗管理の対象、店舗評価指標 |
| C | 参考（分析用） | 詳細分析・原因究明に使用、定期確認不要 |
| D | 補助（マスタ/設定） | マスタデータ、設定値、ラベル情報 |

### 店舗画面（店長視点）

| ランク | 定義 | 判断基準 |
|--------|------|----------|
| S | 最重要（日次確認必須） | 毎日確認すべき数値、売上・利益に直結 |
| A | 重要（週次確認推奨） | 週次で傾向把握、シフト・発注判断に影響 |
| B | 標準（月次確認） | 月次振り返り、改善施策立案に使用 |
| C | 参考（必要時確認） | 問題発生時の原因分析、詳細確認用 |
| D | 補助（設定/入力） | 設定入力、マスタ情報、直接管理対象外 |
